# Data Analysis Portfolio

This repository contains data analysis projects developed using Python and Jupyter Notebook.

## Projects

### Sales Data Analysis
Analysis of sales data to explore trends and visualize monthly performance.

Tools used:
- Python
- Pandas
- Matplotlib

### Aircraft Sensor Data Analysis
Analysis of simulated aircraft sensor data to monitor system behaviour and detect anomalies.

The project includes:
- Exploratory Data Analysis
- Sensor correlation analysis
- Time series visualization
- Anomaly detection

Tools used:
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
